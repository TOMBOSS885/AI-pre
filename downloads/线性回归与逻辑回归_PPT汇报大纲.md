## 二、PPT 大纲：大纲长什么样（初学者照做版）

### 2.0 这份大纲怎么用

**大纲 = 17 张幻灯片的"规格卡"清单**（封面 + 目录 + 14 页主线 + 结束页；另有 2 页可选扩展）。每页一张规格卡，固定 6 个字段：

| ② 一句话结论 | 观众就算只记住这一句也不算白听 | 副标题或页脚 |

| ④ 页面上的图 | 画什么 / 用网页哪张截图 | 页面主体（图比文字大） |
| ⑤ 版式 | 左文右图还是上下排 | 排版参考 |
| ⑥ 演讲者备注 | 口语讲什么、何时切网页演示 | PPT 备注栏（放映时不显示） |

**制作五步（照做即可）：**
1. 新建空 PPT，做 17 页骨架：封面、目录、14 页正文、结束页；
2. 逐页按规格卡填：先放大标题 → 贴图 → 抄 3~4 条要点 → 放公式 → 页脚写页码；
3. 截图网页素材（清单见 2.3），每张截图前先把网页调到指定状态；
4. 把《逐页汇报稿.md》对应段落贴进每页备注栏；
5. 自查一遍：一页是否只有一个结论？字号是否 ≥ 24pt？蓝=线性回归、绿=逻辑回归的配色是否统一？

### 2.1 版式与配色规则（所有页面统一遵守）

- 一页一个结论：标题即结论，正文只放支撑它的 3~4 条短要点。
- 配色与网页一致：**线性回归内容用蓝色系，逻辑回归内容用绿色系**，红色只用来标"错误/损失/残差"。
- 公式单独占一块，用最大字号；公式下面加一行"大白话"翻译（例：MSE = 平均[（预测 − 真实）²] → 大白话：误差平方的平均）。
- 图占页面的 50% 以上，文字宁少勿多；观众 3 秒扫完一页。
- 每页右下角放页码 + 板块进度（如 "2/14 · 线性回归"）。
- 正文不用长句；讲稿全部放备注栏，不贴到页面上。

#### 第 3 页｜线性回归的模型（75 秒 · 1:30–2:45）

- **大标题：** 线性回归 = 找一条最好的直线
- **一句话结论：** w 管倾斜，b 管高低
- **页面要点（照抄）：**
  - 大字公式：**ŷ = w·x + b**
  - w = 斜率：x 多 1 小时，预测值多 w 分（示例：w = 5 → 多学 1 小时，平均多 5 分）
  - b = 截距：整条直线的高度
  - 不要求穿过每个点，找的是总体趋势
- **图：** 网页 #linear 默认截图（散点 + 直线），在旁边用箭头标出 w（倾角）与 b（与纵轴交点）
- **版式：** 左图右文；公式放右侧顶部最大字号
- **备注：** 强调"这是教学模拟，不代表真实因果关系"；超时则跳过"多特征"一句。

#### 第 4 页｜残差与均方误差（90 秒 · 2:45–4:15）· 演示① 35 秒

- **大标题：** 哪条直线更好？看 MSE
- **一句话结论：** 误差平方再平均，大错罚得更重
- **页面要点（照抄）：**
  - 大字公式：**MSE = (1/n)·Σ(ŷ − y)²** → 大白话：误差平方的平均
  - 残差 = 同一个 x 上"预测 − 真实"的竖直距离（不是点到直线的垂足）
  - 直接相加会正负抵消 → 所以先平方
  - 大误差被平方放大 → 离群点会明显拉动直线
- **图：** 网页 #linear 勾选"显示残差"后的截图（散点 + 直线 + 红色竖线）
- **版式：** 上图下文；公式与"大白话"并排
- **备注：** 讲完 30 秒后切网页 #linear 演示 35 秒：拖 b（10s）→ 拖 w（10s）→ 指残差线与 MSE 联动（10s）→ 重置切回（5s）。口令："我们不凭感觉选好看的线，用 MSE 比较。"

#### 第 5 页｜梯度下降如何学习（100 秒 · 4:15–5:55）· 演示② 40 秒

- **大标题：** 参数怎么自动变好？沿负梯度下山
- **一句话结论：** 学习率决定每步走多大
- **页面要点（照抄）：**
  - 大字公式：**w ← w − α·(2/n)·Σ(ŷ − y)·x**
  - 梯度 = 当地最陡的"上坡方向"；沿反方向走 = 下山（让损失变小）
  - 学习率 α 太大 → 震荡甚至发散；太小 → 下降太慢
  - 梯度下降是"求解方法"，模型本身还可以用最小二乘法直接解
- **图：** 两张损失曲线对比截图：#descent 用 α=0.01 播放一段（左，下降）与 α=0.05（右，发散）
- **版式：** 上图下文；公式配一句大白话："每次朝下山方向挪一小步"
- **备注：** 讲完 60 秒后切 #descent 演示 40 秒：0.01 播 15s → 重置换 0.05 看发散 15s → 对比轨迹 10s。口令："模型规定长什么样，梯度下降规定怎么学。"

#### 第 6 页｜从分数走向分类（50 秒 · 5:55–6:45）

- **大标题：** 换个问题：从分数到"能不能通过"
- **一句话结论：** 标签变成 0/1 之后，直线不够用了
- **页面要点（照抄）：**
  - 标签只有两个值：0 = 未通过，1 = 通过（全汇报约定"通过 = 正类"）
  - 直线输出可能小于 0 或大于 1，不能直接当概率
  - 解决办法：先算线性得分 z，再用 S 形曲线把结果压到 0~1 之间
- **图：** 上下对比：上图一条直线冲出 [0,1] 区间（红叉标注）；下图 S 曲线稳稳夹在 0 和 1 之间（素材：可自画，或用网页 Bliss 实验勾选"叠一条普通直线"的截图）

- **备注：** 强调"通过 = 正类"这个约定后面每一页都要用。

#### 第 7 页｜Sigmoid 与概率（90 秒 · 6:45–8:15）· 演示③ 30 秒

- **大标题：** S 形曲线：把得分变成概率
- **一句话结论：** p = 0.8 是"80% 概率通过"，不是 80 分
- **页面要点（照抄）：**
  - 大字公式：**p = 1 / (1 + e^(−z))**
  - z = 0 → p = 0.5（五五开）
  - z 越大 p 越接近 1；z 越负 p 越接近 0；概率永远在 0~1 之间
  - 曲线中间变化快、两端变平
- **图：** 网页 #logistic 截图（S 曲线 + z=0 处的点 + 概率读数）
- **版式：** 左图右文；公式配大白话："得分越高，通过概率越大，但永远不会超过 100%"
- **备注：** 讲完 60 秒后切 #logistic 演示 30 秒：点 z=0（8s）→ 向正、再向负拖动（12s）→ 停在 ≈0.8 强调"是概率不是分数"（10s）。

#### 第 8 页｜交叉熵如何训练（75 秒 · 8:15–9:30）

- **大标题：** 模型怎样为错误"付出代价"？
- **一句话结论：** 自信地错，罚得最重
- **页面要点（照抄）：**
  - 小字公式：**J = −(1/n)·Σ[y·ln p + (1−y)·ln(1−p)]**（想了解推导看学习网页）
  - 三张卡片（真实标签都是"通过" y=1）：
    - 预测 p = 0.9 → 损失很小 ✓
    - 预测 p = 0.6 → 损失中等
    - 预测 p = 0.01 → 自信地错 → 损失很大 ✗
  - 训练就是让这个损失下降；选阈值是之后独立的一步
- **图：** 自画三张卡片（绿框，第三张加红框）；备选素材：#lossPlot 选 y=1 的曲线截图
- **版式：** 三卡横排，公式小字放页脚
- **备注：** 不展开对数计算，只用三张卡讲"越自信越错，代价越大"。

#### 第 9 页｜阈值与混淆矩阵（100 秒 · 9:30–11:10）· 演示④ 35 秒

- **大标题：** 概率怎么变成决定？定一个阈值
- **一句话结论：** 阈值决定"漏掉"和"误报"怎么分配
- **页面要点（照抄）：**
  - 决策规则大字：**p ≥ τ → 预测"通过"**
  - 混淆矩阵 2×2（行 = 实际，列 = 预测）：
    | | 预测通过 | 预测未通过 |
    | 实际通过 | TP（对） | FN（漏了） |
    | 实际未通过 | FP（误报） | TN（对） |
  - τ = 0.5 只是常见起点；调低 τ → 预测"通过"变多：漏掉的变少、误报变多
  - 阈值要在验证集上选，不能拿测试集反复试
- **图：** 网页 #threshold 截图（12 个概率点 + 阈值横线 + 四格矩阵）
- **版式：** 上图下文；决策规则放最大字号
- **备注：** 讲完 65 秒后切 #threshold 演示 35 秒：0.50 读四格（10s）→ 0.30（10s）→ 0.70（10s）→ 回 0.50 强调"概率没变、模型没重训"（5s）。

#### 第 10 页｜二维决策边界（100 秒 · 11:10–12:50）

- **大标题：** 边界在哪里？还是一条直线
- **一句话结论：** S 形的是"概率曲线"，输入空间里的边界本身是直线
- **页面要点（照抄）：**
  - 两个特征（学习时长 x₁、练习完成量 x₂）时，p = 0.5 的位置满足：
  - 大字公式：**w₁·x₁ + w₂·x₂ + b = 0** → 二维平面里的一条**直线**

#### 第 11 页｜两种任务怎样评价（90 秒 · 12:50–14:20）

- **大标题：** 指标要配任务
- **一句话结论：** 回归看误差大小，分类看错误类型
- **页面要点（照抄）：**
  - 左卡（回归 · 蓝）：RMSE 与目标同单位（"分"）；R² 可以**为负**——表示比"全部预测平均值"还差

#### 可选扩展页 15｜正则化与过拟合（约 90 秒，20 分钟版 / 被追问时）

- **大标题：** 什么时候直线会"学过头"？
- **要点（照抄）：**
  - 过拟合信号：训练损失低、验证损失高；欠拟合：两者都高
  - 岭回归（L2）：损失 + λ·Σw² → 收缩系数；Lasso（L1）：损失 + λ·Σ|w| → 可把系数压到 0
  - 逻辑回归默认带 L2 正则化；数据完全可分时无正则参数会一直变大
  - 多分类怎么办：softmax + 多类交叉熵（本汇报只讲二分类）

#### 可选扩展页 16｜ROC 曲线与 AUC（约 90 秒，20 分钟版 / 被追问时）

- **大标题：** 一个阈值不够看，那就把所有阈值都看一遍
- **要点（照抄）：**
  - 混淆矩阵只对应一个阈值；ROC 曲线遍历所有阈值：横轴 FPR（误报率）、纵轴 TPR（召回率）
  - AUC = 随机挑一个正样本排在随机负样本前面的概率 → 衡量排序质量
  - 类别不平衡时用 PR 曲线（横轴 Recall、纵轴 Precision）更敏感
  - 结论：模型质量看 AUC / LogLoss；业务阈值按代价在验证集上选

- **备注：** 一句话版："AUC 越大，模型把正例排在负例前面的能力越强。"

- 上台前：网页开"汇报模式"、四个实验各重置一次、14 张素材截图备好。

### 3.3 统一口径（PPT 与口播不得违反）

1. 残差 = ŷ − y，是竖直距离；MSE 梯度含系数 2。
2. 通过 = 1 = 正类；p ≥ τ 判通过；混淆矩阵行 = 实际、列 = 预测。
3. "先算线性得分、再经 Sigmoid 得到概率，整体由交叉熵训练"——禁止说"先最小二乘再加 Sigmoid"。
4. 只改阈值：概率与 LogLoss 不变；"调低阈值"不保证 Precision 严格下降。
5. 数据是教学模拟，不宣称因果关系；外推（如 31°F）需明确声明。

### 3.4 备答清单（现场提问兜底）

- 线性回归能做分类吗？→ 可阈值化但不保证合法概率，本次用概率分类模型。
- 为什么逻辑回归用交叉熵而不用 MSE？→ 伯努利负对数似然给出概率依据；MSE 的梯度含 σ'(z)，在两端趋 0 时学习更慢。
- 哪个算法更好？→ 看预测目标与评价目标，两者任务不同，不可脱离数据排名。
- 逻辑回归和神经网络什么关系？→ 相当于线性加权 + Sigmoid 的单单元；多层网络增加中间表示与非线性。
- 权重越大越重要吗？→ 受单位、尺度、相关性影响，不能直接跨特征比较。
- R² 为负正常吗？→ 正常，表示比该数据均值基线更差。
- 阈值 0.5 对吗？→ 只是常见起点，应按代价在验证集上选。
