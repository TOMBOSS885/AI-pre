# 经典机器学习算法：线性回归与逻辑回归 · 小组汇报总览

本次汇报只覆盖经典监督学习里的两个线性基线。叙事采用“同一场景、两个问题、一套学习流程”：从预测考试分数理解线性回归，再将目标切换为是否通过，理解逻辑回归；最后回到指标、规范实验和算法对照。面向本科初学者，默认4人，可按人数合并。

**标准时长18分钟，14页；可压缩到15分钟，也可加2分钟问答形成20分钟。** 网页用于课前/课后系统学习，台上只展示4段交互，不从头逐屏浏览整站。

全部学生样本、关系与概率数值均为教学模拟，不代表真实教育规律。残差统一约定为预测值减真实值。分类统一约定：通过=1=正类，未通过=0=负类；p≥τ预测通过。若后续替换真实数据，需要重新说明样本来源与模型验证结果。

## 排练与演示安排

1. 先分工阅读学习网页，确保每人能用自己的话解释模型、损失、优化和评价的关系，再熟悉逐页讲稿。
2. 每位主讲单独计时一轮，随后全组连讲一次；以实际结果校准页间速度，当前时间表是预算而非实测时长。
3. 口语稿共3280个汉字（含标点/拉丁字符共3651字符）。按约220汉字/分钟估算，口述约14分55秒，演示约2分20秒，另有约45秒用于停顿和衔接；口述与演示中的讲解可重叠。
4. 台上只打开预定的4个网页模块；提前恢复默认数据、检查投影字号，并保存四个演示画面的截图作为设备故障时的替代。
5. 设三个进度提醒：5:55进入逻辑回归，12:50进入评价，15:50进入总结。落后超过30秒时，执行15分钟方案中的删减点。
6. PPT正文只放大纲；讲稿与来源放备注或单独文档。后续补充图表时明确区分教学示意、现场计算结果与真实实验结果。
