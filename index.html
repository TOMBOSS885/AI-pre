01

PPT 03–04 · 模型与损失

一条直线，怎样才算拟合得好？

把每条学习记录画成一个点。横轴是学习时长，纵轴是考试分数。线性回归用 ŷ = wx + b 描述平均趋势：w 决定倾斜程度，b 决定整体高度。

直线拟合实验

教学模拟 · 10个样本现场 · PPT 04 · 35秒
实际分数预测直线残差

试着让 MSE 更小

均方误差 MSE—越小，当前训练样本的平方误差越小

读懂参数

w 是“每增加一单位 x”

例如 w = 5，表示在这个模型中，学习时长增加 1 小时，预测分数增加 5 分。b 是 x = 0 时的预测值。超出数据范围的解释要谨慎。

衡量偏差

距离有方向，平方不会抵消

约定误差 eᵢ = ŷᵢ − yᵢ。把误差直接相加，正负可能抵消；平方后再求平均，得到 MSE。大误差会受到更强惩罚。

本网页统一采用MSE = (1/n) Σᵢ (ŷᵢ − yᵢ)²

n 是样本数，yᵢ 是实际值，ŷᵢ 是预测值。MSE 的单位是“分²”；RMSE = √MSE 的单位回到“分”。

深入一点：多元模型、最小二乘解与基本假设

多元线性回归写作 ŷ = w₁x₁ + ⋯ + w_dx_d + b。这里的“线性”指对参数线性；加入预先构造的 x² 特征后，仍可对参数保持线性。

一元最小二乘解：w* = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²，b* = ȳ − w*x̄，前提是 x 存在变化。多元情况下可用稳定的数值线性代数求解，无需手工求逆。

用线性模型近似条件均值是建模选择。误差独立、同方差等假设影响传统统计推断；正态性主要用于经典的小样本区间和检验，不能说“只有数据正态才能拟合”。最小二乘对离群点较敏感，也不证明因果。

依据：Google MLCC：线性回归 · 损失

PPT 05 · 参数学习

训练，就是沿着误差下降的方向走

刚才是我们手动调参数。梯度下降让计算机重复这个过程：计算预测、求损失的梯度、沿负梯度更新参数。学习率 α 控制每步走多远。

同一批数据，观察训练轨迹

从 w = 0、b = 0 开始现场 · PPT 05 · 40秒

纵轴使用 log₁₀(1 + MSE)，方便同时看见收敛和发散；右侧显示实际 MSE。这里直接使用原始小时数与分数。

第 0 步 / MSE—

先预测曲线会向哪里走，再按播放。

梯度都先用旧参数计算，再同时更新w ← w − α · (2/n) Σᵢ (ŷᵢ − yᵢ)xᵢb ← b − α · (2/n) Σᵢ (ŷᵢ − yᵢ)

这里的目标是 MSE，因此梯度含系数 2。如果目标写成 ½MSE，梯度中的 2 会消失。

观察任务：先用 α = 0.01 播放约 5 秒，再选择 0.05 重新播放。凸的损失曲面也可能因为步子过大而无法收敛。
深入一点：收敛、标准化与正则化

对线性回归的平方目标，梯度下降在合适学习率等条件下可以趋近最小值。停止可以依据迭代次数、梯度大小或损失变化，不能只看动画“动得慢”。本演示最多 240 步，不宣称已经达到最优。

特征尺度差异很大时，优化会更困难。标准化必须只用训练集估计均值和标准差，再应用到验证集、测试集。岭回归在损失中加入 λΣwⱼ²，限制过大的系数；λ 由验证数据选择，通常不惩罚截距。

梯度下降只是求解方式之一。普通最小二乘还有数值线性代数解法，“模型”与“优化算法”是两个不同层次。

依据：Google MLCC：梯度下降 · Stanford CS229 讲义

PPT 06–08 · 概率模型与分类损失

从一个线性得分，到 0 和 1 之间

如果问题变成“是否通过”，标签就变成 0 或 1。普通直线输出可能小于 0 或大于 1，不能直接当概率。逻辑回归先计算线性得分 z = wᵀx + b，再用 Sigmoid 映射得到正类概率 p。

二分类逻辑回归p = P(y = 1 | x) = σ(z) = 1 / (1 + e⁻ᶻ)

有限 z 的理论输出在 (0, 1) 内。z = 0 对应 p = 0.5；z 越大，正类概率越大。界面只显示经过舍入的数值。

摸一摸 S 形曲线

输入是 z，不是小时数现场 · PPT 07 · 30秒

这是概率关于 z 的曲线。二维输入空间中的分类边界将在下一章单独讨论。

正类“通过”的概率50.0%z = 0，p = 0.5

先判断：z 从 0 变到 2，概率会增加到 100% 吗？

模型怎样为错误的概率“付出代价”？

逻辑回归通常最小化二元交叉熵，也叫 LogLoss。真实 y = 1 时，只看 −ln(p)；真实 y = 0 时，只看 −ln(1 − p)。预测越自信却越错，损失越大。

n 个样本的平均二元交叉熵，ln 为自然对数J = −(1/n) Σᵢ [yᵢ ln(pᵢ) + (1 − yᵢ) ln(1 − pᵢ)]

分类阈值不出现在这个公式中。模型直接调整 w、b 使这个损失下降。

单个样本的交叉熵

比较“自信地对”与“自信地错”
当前单样本损失—
不要把逻辑回归理解为“先用最小二乘拟合，再加一个 Sigmoid”。它是整体概率模型，参数从一开始就由分类损失训练。Sigmoid 本身也不保证概率经过良好校准。
深入一点：为什么仍然叫回归？交叉熵从哪里来？

逻辑回归对对数几率建模：ln[p/(1 − p)] = wᵀx + b。线性的是对数几率。在机器学习任务划分中，它常作为分类模型使用。

若标签服从伯努利分布，单样本概率为 pʸ(1 − p)¹⁻ʸ。把样本似然相乘、取负对数并求平均，就得到交叉熵。这比“曲线看起来合适”给出了更明确的概率依据。

无正则化时，梯度为 ∇wJ = (1/n)Σ(pᵢ − yᵢ)xᵢ，∂J/∂b = (1/n)Σ(pᵢ − yᵢ)。更新形式同样是沿负梯度，但预测函数与线性回归不同。数据完全可分时，无正则化参数可能持续增大，实际常使用正则化。

依据：Google MLCC：Sigmoid · 交叉熵与正则化 · CS229：概率推导

PPT 09 · 概率与决策

同一组概率，阈值决定怎样分类

模型给出概率后，还需要一条决策规则。本网页统一约定：p ≥ τ 时预测“通过”，否则预测“未通过”。τ 是分类阈值，0.5 只是常见选择。

你判断的“通过”有多可靠？

Precision = TP / (TP + FP)

在所有预测通过的同学里，有多少实际通过？精确率关心预测正类的可信程度。

实际通过的同学找到了多少？

Recall = TP / (TP + FN)

在所有实际通过的同学里，有多少被识别出来？召回率关心漏掉多少正例。

先预测再操作：阈值降低，预测为正类的样本会增加或不变，Recall 不会下降，FP 不会减少。Precision 的具体变化取决于新增样本的真实标签，并不保证单调。
深入一点：怎样选阈值？为什么不能只看准确率？

Accuracy = (TP + TN)/n。如果 100 人里只有 5 人未通过，把所有人都预测为通过，准确率仍有 95%，却完全发现不了未通过者。评价前先明确谁是正类、哪种错误代价更高；如果把“未通过”设为正类，指标的解读也要相应调整。

阈值应根据任务代价或目标指标，在验证集上选择。测试集用于最后一次评价，不能反复调阈值追求测试分数。Precision 的分母为零时无定义，本页显示“—”；Recall 的分母为零时同理。

F1 = 2PR/(P + R)，平衡精确率和召回率。ROC/AUC 和 PR 曲线考察多个阈值，适合课后扩展。本次汇报先把混淆矩阵与 P/R 讲清楚。

依据：scikit-learn：决策阈值 · Google MLCC：评价指标

PPT 10 · 输入空间中的边界

S 形概率，不等于弯曲的决策边界

当输入包含两项特征时，例如标准化后的学习时长 x₁ 和练习完成量 x₂，线性得分为 z = w₁x₁ + w₂x₂ + b。图中的底色表示预测类别，点的形状表示真实类别。

移动边界，观察误分类

阈值固定 0.5 · 原始二维线性特征
圆点：实际1◇ 菱形：实际0青色背景：预测1红圈：误分类

p = 0.5 ⇔ z = 0w₁x₁ + w₂x₂ + b = 0

至少一个权重非零时，这是二维空间中的直线。一般阈值 0 < τ < 1 对应 z = ln[τ/(1 − τ)]。

深入一点：逻辑回归能不能产生非线性边界？

可以通过非线性特征变换。例如 z = w₁x₁² + w₂x₂² + b，其 z = 0 在原始二维空间中可以呈现椭圆等曲线。模型对变换后的特征仍是线性的。模型复杂度增加后，也更需要验证与正则化。

当 w₁ = w₂ = 0 时，概率处处相同，通常没有普通的分割直线。若此时 b = 0，所有位置 p 都等于 0.5，按本页的 ≥ 规则全判为正类；不能除以零强行画线。

经典算法对照：共同流程，不同目标

比较维度线性回归二分类逻辑回归

回归：误差到底有多大？

MAE = (1/n)Σ|yᵢ − ŷᵢ|，可以理解为平均绝对偏差。RMSE = √MSE，对大误差更敏感。二者均与目标同单位，更便于解释。

比较模型时，要使用同一数据划分和同一指标。不同量纲、不同任务的 MSE 与交叉熵数值不能直接比大小来评选算法。

R² 并不总在 0 和 1 之间

R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²。它可以为负，表示在该评价数据上，预测甚至不如恒预测该数据的均值。

当实际标签全相同时，分母为零，定义需特殊处理。R² 也不是“准确率”，更不代表因果解释比例。

PPT 12 · 从理解走向实验

先留出没见过的数据，再谈模型效果

一张漂亮的训练拟合图还不够。汇报中的实验建议使用同一批输入，分别准备连续标签与二分类标签，明确比较的是两种任务的机制。若使用成绩阈值生成类别，需要说明这个人为定义。

定义任务与数据

明确特征、标签、正类和评价指标。检查缺失值、重复记录与标签来源。

先划分数据

训练集学参数，验证集选超参数和阈值，测试集用于最终评价。

训练并验证

只在训练集拟合标准化。和简单基线比较，观察是否过拟合。

解释测试表现

回归报告偏差尺度，分类分析错误类型。记录划分方法与局限。

数据泄漏：先用全体数据算均值和标准差，再划分训练与测试，会让测试信息进入训练流程。按时间产生的数据还应考虑按时间划分；同一人的多条记录要防止跨组泄漏。
可运行示例：同一组模拟输入，完成两种任务

这段代码生成可复现的教学数据。回归标签和分类标签各自由不同机制生成，共享输入；没有把分类标签设成分数的简单阈值。80% 用于训练与验证，20% 保留为测试。阈值 0.5 在这里预先固定，未用测试集调优。scikit-learn 的逻辑回归包含其默认正则化。

import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.metrics import mean_squared_error, classification_report

rng = np.random.default_rng(42)
X = rng.normal(size=(300, 2))  # 两个模拟特征
y_score = 65 + 8*X[:, 0] + 5*X[:, 1] + rng.normal(0, 5, 300)
p = 1 / (1 + np.exp(-(1.3*X[:, 0] + 0.8*X[:, 1])))
y_pass = rng.binomial(1, p)
trainval, test = train_test_split(
    np.arange(300), test_size=0.2, random_state=42, stratify=y_pass)
train, valid = train_test_split(
    trainval, test_size=0.25, random_state=42, stratify=y_pass[trainval])

reg = make_pipeline(StandardScaler(), LinearRegression())
clf = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
reg.fit(X[train], y_score[train])
clf.fit(X[train], y_pass[train])

# 如需选超参数或阈值，只使用 valid，选择后再看 test
y_hat = reg.predict(X[test])
prob = clf.predict_proba(X[test])[:, 1]
label = (prob >= 0.5).astype(int)
print('测试 RMSE:', np.sqrt(mean_squared_error(y_score[test], y_hat)))
print(classification_report(y_pass[test], label, zero_division=0))
# zero_division=0 是报告约定，数学上分母为零的比例无定义

依赖：Python、NumPy、scikit-learn。此处提供流程代码，不预填实验成绩。你们可以运行后加入实际输出、残差图和混淆矩阵，并注明模拟数据。

汇报时容易被问到的四个问题

线性回归能不能做分类？ 可以把连续输出再阈值化用于某些场景，但普通线性输出不保证合法概率，本次使用专门的概率分类模型。

哪个算法更好？ 先看预测目标。两者通常处理不同任务，不能脱离数据和评价目标排高低。

逻辑回归和神经网络有什么联系？ 它相当于线性组合接一个 Sigmoid 的简单计算单元；多层网络增加中间表示与非线性，能力和训练复杂度也不同。

权重越大越重要吗？ 权重受特征单位、尺度和相关性影响，不能直接用原始系数绝对值跨特征排名。
